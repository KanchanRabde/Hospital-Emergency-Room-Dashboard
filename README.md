# 🏥 Hospital Emergency Room Analysis Dashboard (Excel)

An interactive **Excel Dashboard** designed to analyze Emergency Room (ER) performance, patient demographics, wait times, and department referrals to optimize overall operational efficiency.

---

## 📊 Dashboard Overview

![Hospital Emergency Room Dashboard](Hospital%20Dashboard%20Final%20.jpg)

---

## 🔑 Key Metrics (KPIs)

* **Total Patients:** 464
* **Average Wait Time:** 35.19 Minutes
* **Patient Satisfaction Score:** 5.09 / 10
* **On-Time Service Rate:** 39% Within Time | 61% Delay

---

## 💡 Key Insights & Features

* **Admission Breakdown:** 50% Admitted (231 patients) vs 50% Not Admitted (233 patients).
* **Gender Demographics:** Balanced distribution with 237 Females (51%) and 227 Males (49%).
* **Age Group Distribution:** Highest patient volume is seen in the **30-44 age group** (95 patients), followed by **45-59 years** (85 patients).
* **Department Referrals:** The majority of patients had no specific referral (252 patients), while **General Practice** (91) and **Orthopedics** (67) were the top referred departments.

---

## 🛠️ Tools & Functions Used

* **Microsoft Excel:** Data Cleaning, Pivot Tables, Pivot Charts, Slicers, and Custom Formatting.

---

## 🚀 How to View / Run

1. Clone or download this repository.
2. Open the `.xlsx` file using **Microsoft Excel**.
3. Interact with slicers (Year, Month) to filter insights dynamically.
